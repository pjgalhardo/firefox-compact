Compact Comfort needs its updated compact.css in this profile. After replacing it, fully quit this Firefox profile with Command + Q, reopen it, and load this add-on again if it is temporary.

Mac, Linux, or manual setup
  1. In about:config, set toolkit.legacyUserProfileCustomizations.stylesheets to true.
  2. Open about:support and click Open Folder next to Profile Folder. Make a chrome folder there if it's missing.
  3. Save the CSS below as compact.css in that folder.
  4. Add @import "compact.css"; as the first line of both userChrome.css and userContent.css (create them if needed).
  5. Fully restart Firefox.
